# New-Game

A 2D game development project built with C++ and SDL2.

New-Game is a personal game development project focused on learning the fundamentals of game programming, including player movement, projectile mechanics, gravity, enemy behavior, and tile-based world rendering.

The project is developed step by step, with an emphasis on understanding the underlying mechanics and building game systems from scratch.

## Features

- **Player System:** Player positioning and movement mechanics.
- **Projectile System:** Bullet creation, movement, and updates.
- **Physics Experiments:** Gravity and movement behavior.
- **Tile-Based World:** Tile types and world-rendering logic.
- **Enemy System:** Enemy behavior and animation development.
- **2D Rendering:** Game graphics rendered using SDL2.

> Note: This project is a work in progress. Features and gameplay mechanics may change as development continues.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/programmerMrleader/New-Game.git
```

### 2. Navigate to the Project Directory

```bash
cd New-Game
```

### 3. Configure SDL2

Configure the SDL2 header files, libraries, and runtime dependencies for your compiler and target architecture.

If the project uses SDL2 extension libraries, make sure those dependencies are configured as well.

### 4. Build and Run

Open the project in your configured IDE or build system, compile the source files, and run the generated executable.

The exact build commands depend on the project's current configuration.

## Project Goals

The primary goals of this project are to:

- Understand the SDL2 game loop and rendering pipeline.
- Practice object-oriented programming in C++.
- Implement player and enemy systems.
- Develop projectile and physics mechanics.
- Learn tile-map generation and rendering.
- Implement collision detection and game-state management.
- Build a playable 2D game through iterative development.
